# 06 · Business Model

## Model in one line

**B2B plant software: private/on-prem deployment, annual site license, required early implementation services, recurring support — founder-led sales into regulated manufacturing.**

## Diagram

```
Customer plant
    │
    ├─ Annual MOID Plant license (primary ACV)
    ├─ Implementation package (year-0 cash + success)
    ├─ On-prem appliance setup (optional add-on)
    └─ Overage services / multi-site expansion
            │
            ▼
     Deployed on plant LAN (preferred)
     Hosted single-tenant only for time-boxed pilot
```

## Revenue streams

| Stream | Type | Working default |
|--------|------|-----------------|
| MOID Plant annual license | Recurring | ₹8L list / plant / year |
| Standard implementation | One-time | ₹2.5L |
| On-prem appliance setup | One-time | ₹3L |
| Pilot success package | One-time | ₹1.25L (software free in pilot window) |
| Multi-site incremental | Recurring | 20% off list site 2+ |
| Overage eng days | Services | ₹8,000 / day |
| Premium support / QBR | Recurring optional | Custom |

## Why this model (not pure SaaS PLG)

| Constraint | Implication |
|------------|-------------|
| Plant IP / air-gap | On-prem primary |
| High-touch ontology | Services attach early |
| Auth/tenancy incomplete for public SaaS | No self-serve multi-tenant year 1 |
| Trust sale | Pilot + demo on real data |

## Cost structure

| Cost | Notes |
|------|-------|
| Founder / engineering | Dominant COGS substitute early |
| Implementation time | Budget 10–20 eng-days per standard plant |
| Support | Target &lt; 8h/month average after stabilize |
| Travel | On-site optional; price into appliance/impl if needed |
| Legal | One-time templates + per deal review |
| LLM cloud | Avoid as structural COGS; local LLM default |
| Hosting | Only if you host pilot; isolate per customer |

## Unit economics targets

| Stage | Target |
|-------|--------|
| Year-1 revenue per plant (list-ish) | License 8L + impl 2.5L ≈ **₹10.5L** (+ appliance if needed) |
| Delivery cost standard plant | ≤ 15 eng-days fully loaded |
| Blended gross margin after 3 plants | **&gt; 55–60%** |
| Customer payback narrative | **&lt; 12 months** conservative |
| CAC | Founder time; no paid acquisition year 1 |
| Logo discount | Only with case rights; protect lifetime ACV |

## Expansion paths

1. More lines / product families in same plant (services + possible uplift).  
2. Site 2+ in group (multi-site discount).  
3. Modules later: advanced CAPA, SOP intelligence, multi-site rollup.  
4. Premium QBR / on-site quarterly.

## Metrics (business)

| Metric | Definition |
|--------|------------|
| Plants live | Paying + weekly active use |
| Pilot conversion | Pilots → annual contracts |
| ACV | Annual license per plant |
| Year-1 TCV | License + impl (+ appliance) |
| Services attach rate | Impl / license |
| Time-to-value | Kickoff → first trusted monthly review |
| Support hours / plant / month | Load |
| NRR | Later, with multi-site |

## What we will not sell as the model

- Unlimited free custom forever.  
- Per-seat nickel-and-diming of executives as primary revenue.  
- AI token markup as headline SKU.  
- Pure perpetual license without AMC (if forced: AMC 20%, min ₹1.5L/yr).
