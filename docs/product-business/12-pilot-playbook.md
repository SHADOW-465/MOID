# 12 · Pilot Playbook

## Purpose

De-risk purchase for the plant and de-risk unpaid labor for you. Every pilot has **dates, fee, success criteria, and convert/kill**.

## Commercial default

| Item | Value |
|------|-------|
| Duration | **8 weeks** |
| Fee | **₹1,25,000** (`MOID-PILOT`) |
| Software | Free **only** during pilot window |
| Convert credit | Full pilot fee against `MOID-IMPL-STD` if signed within **30 days** of pilot end |
| Scope | One plant, one primary product family, agreed gates |
| Users | GM + QM + 1–2 entry users |
| Environment | Decide week 0: on-prem **or** single-tenant hosted pilot |

## Success criteria (default — customize in SOW)

Must achieve **≥4 of 5**:

1. **Parity / honesty:** Agreed clean month matches ground truth within tolerance **or** differences documented (sheet claim vs recomputed).  
2. **Entry:** Entry users complete in-scope period without parallel spreadsheet as primary.  
3. **Trust:** QM uses View Source successfully on ≥3 KPIs.  
4. **Audit:** One audit package generated; QM rates “useful” in writing.  
5. **Money or time:** COPQ baseline signed **or** measured time saved on one report cycle.

## Week plan

| Week | Focus | Exit gate |
|------|-------|-----------|
| 0 | SOW signed, access, IT path | Kickoff scheduled |
| 1 | Kickoff; grain + cost draft; file inventory | RACI clear |
| 2 | History load; MOD verify critical sheets | Mappings accepted |
| 3 | Dashboard vs ground truth / findings | Method agreement |
| 4 | Data Entry live | First real entry day |
| 5 | QM drills (defect/size/SPC) | QM self-serve |
| 6 | COPQ and/or audit drill | Artifact produced |
| 7 | GM monthly review simulation | GM feedback logged |
| 8 | ROI letter + commercial proposal | Go / no-go |

## RACI

| Workstream | You | Customer QM | Customer GM | IT |
|------------|-----|-------------|-------------|-----|
| Ontology / MOD | R | A | C | I |
| Ground truth month | R | A | C | I |
| Entry process | C | A | I | I |
| Deploy / backup | C | I | I | A |
| Success sign-off | C | A | A | I |
| Commercial | R | C | A | C |

R=responsible A=accountable C=consulted I=informed

## Kill criteria (exit early)

- No data access by end of week 2.  
- Champion no-shows twice without reschedule.  
- Hard refusal of both on-prem and hosted pilot.  
- Scope expands &gt;50% without SOW change and fees.  
- Explicit “never buying; research only” after week 1 (offer paid discovery day instead).

## Convert motion

- Week 7: preview Bundle A/B pricing.  
- Week 8: written proposal valid **30 days**.  
- Design partner discount only with **logo + case study + reference** clause.  
- If no: offer data export + wipe certificate; optional paid break-fix support week.
