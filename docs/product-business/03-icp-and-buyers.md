# 03 · ICP & Buyers

## Ideal Customer Profile (year 1)

### Firmographics
- **Industry:** Medical devices (primary); adjacent regulated manufacturing with multi-gate inspection.  
- **Process:** Multi-stage production + inspection; quality already logged in Excel/paper.  
- **Size:** MSME to mid-market **single plant** first.  
- **Geo:** India first (NCR / industrial belts near design partner, then other clusters).  
- **Compliance:** ISO 13485, CDSCO MDR 2017, or similar audit culture.  
- **IT:** Can host a LAN server **or** accept tightly controlled temporary hosted pilot. Limited MES.  
- **Budget:** Can approve roughly **₹5–15L** year-1 software+impl with GM/ops sponsorship.

### Psychographics / triggers
- Painful last audit or fear of next one.  
- Rejection spike quarter with no clean story.  
- New quality head wants “one number.”  
- Excel version chaos / broken links.  
- Corporate asking for COPQ or scrap cost.

### Data signals they are ready
- Will share sample workbooks under NDA.  
- Can name a QM champion and entry owner.  
- GM will attend kickoff and exit review.  
- IT will answer deploy questions in week 1.

## Anti-ICP (disqualify early)

- Already has trusted MES quality module and clean warehouse — only wants prettier charts.  
- Success = “AI predicts defects next week” with no process discipline.  
- Refuses any server (cloud **and** on-prem) and any data access.  
- Procurement is a multi-crore MES RFP only (wrong process).  
- No quality champion; pure tire-kicking.  
- Expects free custom recreation of 40 legacy Excel charts forever.

## Buying committee

| Role | Power | Need from you | How you win them |
|------|-------|---------------|------------------|
| **GM / Plant Director** | Economic buyer | ROI, simplicity, monthly truth | COPQ + clean cockpit + pilot success letter |
| **Quality Head** | Champion | Correct ontology, drills, audit | Their stages/defects mapped; View Source |
| **IT / OT security** | Veto | Air-gap, backup, no leaky AI | Security one-pager + on-prem path |
| **Finance** | Influencer | Cost assumption governance | Signed cost_config story |
| **Operators / PA** | Users | Speed, familiar columns | Entry demo in plant language |
| **Corporate quality** | Later buyer | Standards, multi-site | After site 1 proof |

**Motion:** Sell **GM + QM together**. Bring IT the security page **before** install talk.

## User map

| Role | Frequency | Primary surfaces |
|------|-----------|------------------|
| GM | Weekly–monthly | Dashboard, COPQ, Reports, summary chat |
| QM | Daily | Stage/defect/size, SPC, findings, CAPA, Audit |
| PA / Supervisor | Daily | Data Entry, Staging (bulk) |
| Admin | Rare | Schema, Settings, gated destructive ops |

## Segment priority

| Priority | Segment | Why |
|----------|---------|-----|
| P0 | Med-device plants, Excel rejection culture, India | Design partner + regulation |
| P1 | Other disposables / sterile devices | Same shape |
| P2 | Pharma secondary packaging inspection | Similar scrap story |
| P3 | General discrete scrap analytics | Bigger market, weaker wedge — later |

## Design partner anchor

- **Disposafe**-class: Foley Balloon Catheter / multi-stage medical device, Ballabgarh region narrative in docs.  
- GM = buyer; PA tested early; grain contract partially frozen.  
- Use for depth and reference — negotiate **logo + case study rights** if discounted.
